# 晶体长度测量工具

给坐滴板（96 孔板）蛋白晶体用的**长度测量与照片管理**小工具。

用手机对着显微镜目镜拍一张孔的照片，导进来，工具帮你把孔圈出来、按孔直径
（默认 Φ3.4 mm）算好比例尺，你拉一条线划过晶体，它直接告诉你晶体有多长（μm）。

跑在本地，不联网，照片和数据都在自己电脑上。

---

## 它做什么

1. **导入照片** —— 拖进来、`Ctrl+V` 粘贴，或者手机扫码直传
2. **几何校正** —— 拍斜了、有暗角、有目镜视场圆，先掰正
3. **增强** —— 调亮度对比度（伽马曲线），暗的地方才涨得起来，不会一片死白
4. **标定** —— 工具自动粗定位一个圆，你拖着它对准孔（可缩放、可拉成椭圆、可旋转）。
   孔直径默认按 Φ3.4 mm 算，圆定好了比例尺就出来了
5. **测量** —— 在晶体上拉一条线，直接读出长度（μm）
6. **归档** —— 照片改名、分类、进画廊，测量记录一起存着
7. **导出** —— 带标注的图 + 测量数据

## 怎么跑起来

### 方式一：免安装包（推荐给不写代码的人）

拿到打包好的 `晶体测量工具_*.zip`，**整个解压到一个文件夹**（路径里有中文没问题），
双击里面的 `启动.bat`。

包里自带 Python 运行时，**不需要装任何东西**。第一次启动会在同目录自动建一个
`data/` 文件夹，照片和数据库都在那里。

> ⚠️ 一定要先解压再双击。直接在压缩包里双击是跑不起来的。

### 方式二：从源码跑

需要 Python 3.13（本项目在 3.13 上开发测试）。

```bash
pip install -r requirements.txt
python -m app.launch
```

或者双击 `启动.bat`（它会去找 Python，找不到再退回 PATH 里的 `python`）。

启动后服务在 `http://127.0.0.1:8510`。8510 被占了会自动往后找 8511、8512……
最多试到 8519。

## 开机自启（可选）

想开机就静静在后台跑着，双击 **`安装开机自启.bat`**。

- 不会弹浏览器，也不会弹黑窗口 —— 开了机它在后台待着。你想用时双击 `启动.bat`，
  它发现已经在跑了，就直接把浏览器打开，不会再多起一个
- 关掉：双击 **`取消开机自启.bat`**
- 看现在是什么状态：`python -m app.autostart status`

> ⚠️ 启动项里记着**这个文件夹的路径**。把工具文件夹挪走或改名之后，要**重新双击一次
> `安装开机自启.bat`**，不然开机起的还是老路径。（`status` 命令会主动提醒这件事。）

## 手机传图（可选）

手机拍完直接传进电脑，不用数据线。

1. 电脑上打开测量页，侧栏点「**开启手机传图**」
2. 手机连**同一个 WiFi**，扫屏幕上的二维码
3. 传完的照片立刻出现在电脑端的照片列表里

默认是**关着**的 —— 不开的话，局域网里任何设备都进不来。

**连不上时按这个顺序查：**

1. **只勾了「专用网络」但 WiFi 被 Windows 归成了「公用」** —— 最常见。
   查：`设置 → 网络和 Internet → WLAN → 属性 → 网络配置文件类型`，改成**专用**
2. 第一次启动时弹出的防火墙窗口点了「取消」（= 静默拒绝，且不会再弹）。
   补救：`高级安全 Windows Defender 防火墙 → 入站规则 → 新建规则 → 程序 →
   选中你的 python.exe → 允许连接 → 只勾专用`
3. **WiFi 开了 AP 隔离**（很多访客/企业 WiFi 会开）—— 禁止设备互相通信，
   防火墙全对也连不上。兜底是用 Windows 移动热点
4. 电脑上有 VPN 或多张网卡时，二维码可能编了一个手机到不了的地址 ——
   侧栏可以换一个地址试试

> ⚠️ 防火墙规则是**绑 python.exe 路径**的，不是绑这个工具。批准之后，用同一个
> python.exe 跑的其它程序也会一起开了入站。

## 它是怎么算出来的

- 坐滴板是 **XtalQuest XQ-P-96S-E**（96 Well 2 Big Drops Sitting Drop Plate）
- 点样孔是圆的，**Φ3.4 mm × H0.6 mm**，每池 2 孔 —— 这是默认值，**可以改**（见下）
- 所以：`μm/像素 = 1700 ÷ 长半轴（像素）`
- 检测**只做粗定位**，给一个可调整的起点圆；最终由你把圆对准 —— 精度目标是
  「能算出大概长度」，不是像素级

### 换了别的板子（孔不是 3.4 mm）

测量页右侧「**点样孔直径**」那一栏，填上你自己那块板的真实孔径（单位毫米），
回车即可，不用改代码。

默认值在 `app/config.py` 的 `WELL_DIAMETER_UM`；用户在界面上改过的值存在
`data/settings.json`，优先于默认值。

这个数只影响**新定圆**的照片 —— 已经量过的老照片还按当时那个直径算，不会自己变。
想让哪张老照片也用上新数，把那张图的圆重新拖一下，它上面的测量线会自动跟着重算。

> ⚠️ 填错了，量出来的每个数都会跟着错（差多少倍就差多少倍），按板子规格填准。

```

  launch.py     启动入口：找端口、开浏览器、防重复启动

  api/          导入、文件夹、手机传图
  imageio.py    图像读写 —— **唯一**允许做图像 IO 的模块

  detect.py     孔粗定位

  enhance.py    亮度/对比度（伽马曲线）

  storage.py    照片落盘、路径解析

web/          前端（原生 HTML/JS/Canvas，无构建步骤）
  measure.html  测量页
  gallery.html  画廊页
tests/        测试
```

### 几个踩过的坑（写在这里免得再踩）

- **`.bat` 里一个中文都不能写。** cmd.exe 按本地代码页（CP936）读 .bat，文件却是
  UTF-8 存的，必然乱码；`chcp 65001` 也救不了。所以所有中文提示都由 Python 打印。
- **禁止 `cv2.imread` / `cv2.imwrite`。** Windows 中文路径会**静默失败**（返回 None，
  不报错）。所有图像 IO 走 `app/imageio.py`。
- **`print()` 里别写 emoji。** 输出接真控制台时 Python 走 Windows 控制台 API，
  什么字符都画得出；一旦被重定向成管道或文件就改用 CP936，`⚠️`/`✅` 这类字符
  编不出来会抛 `UnicodeEncodeError` —— 一句 print 就能把整个命令打崩。
- **`.vbs` 要存成带 BOM 的 UTF-16LE。** WScript 读没有 BOM 的文件会当 ANSI，
  路径里的中文会乱掉。
- **函数的默认参数别在定义时读设置。** `def f(real_um=config.WELL_DIAMETER_UM)`
  只在**函数定义那一刻**求值一次，用户后来改了孔直径它也不会跟着变。要写成
  `real_um=None`，再在函数体里现读（见 `app/calibrate.py`）。
