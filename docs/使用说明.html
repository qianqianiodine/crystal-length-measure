使用说明

晶体长度测量工具

给坐滴板单孔照片量晶体长度。拍一张照片 → 让工具认住那个点样孔（3.4 mm）→ 在晶体两头拖一条线，长度就出来了。

2026-09-24 Windows 10 本说明对应压缩包里的这个版本

01先打开它

1

双击文件夹里的 启动.bat。

2

会跳出一个 黑色小窗口。让它开着 —— 关掉它，工具就停了。

窗口里写着一条网址（一般是 http://127.0.0.1:8510）。浏览器会自己打开这个页面； 要是没打开，把那条网址手敲进浏览器地址栏就行。

3

第一次启动时 Windows 可能弹防火墙提示 —— 只勾「专用网络」，别勾「公用网络」。

这一步只影响手机传图。漏掉了也不影响别的功能，以后想补：手机传图连不上时再来处理。

关不掉？ 直接关那个黑窗口就行，不需要别的操作。下次用还是双击 启动.bat。

02界面认路

整个工具就两个页面：测量页（量长度的地方，就是刚打开的这个）和图库页（管理照片的地方，点左上角「图库」进去）。

顶栏的下拉框里是照片自己的名字（比如 50-PEG-G-8-1），不是文件夹名； 量过的照片后面会写「（已量 N 条）」。

03把照片弄进来

四种办法，挑顺手的用：

在测量页

  • 拖进来 —— 把照片文件从文件夹拖到画布上，松手就导入。
  • 粘进来 —— 按 Ctrl+V（截图、微信里的图都能这么贴）。

在图库页

  • 点「导入照片」挑文件，或直接拖到页面上、按 Ctrl+V。
  • 手机传图 —— 见第 13 节。

支持的格式：JPG、PNG、TIF、BMP。一次拖好几张也行。

导入之后先「认名字」

电脑上导入的照片不会直接进图库，而是先停在一个待确认导入的列表里 —— 这是故意的，让你趁这个时候把名字改好：

  1. 每行左边写着工具起的名字（默认用原文件名）。点进输入框就能改。
  2. 名字和其他照片撞了，那一行会变红并给出三个选择：自动加后缀 / 手动改 / 覆盖原图像。 「覆盖原图像」会永久删掉图库里那张同名的照片和它上面的测量记录，拿不准就别选它。
  3. 顶部「这批放到」可以给这批照片选一个文件夹（也可以选「不放进文件夹」）。
  4. 满意了点「确认导入」。点「取消」的话，这批照片要重新传一遍。

手机传图不一样。 在手机上填好名字、孔位再传的，传完就直接进图库，不用再到这个列表里确认（见第 13 节）。

照片会被复制一份。 导入之后照片归工具管，放在 data\ 文件夹里。原来那个文件还在原地，不动它。

加进文件夹以后，工具会在后台先准备起点圆

把照片放进文件夹（导入时选文件夹，或者以后在图库里用「归档…」），工具会在后台 提前算好打开这张图时自动放的圆。之后打开文件夹里的照片会快很多。

  • 后台是一张一张算的；刚放进去就马上打开，可能还没算完，等几秒再开就顺了。
  • 这个圆只是起点：准不准都要你自己拖一下核对（第 04 节）。

04定圆：告诉工具 3.4 mm 有多长

这是唯一一步「必须做对」的事。照片上没有尺子，工具要靠圆来推算出比例 —— 你圈出来的这个圆，就是点样孔的 3.4 mm；有了它，后面每条线的像素数才能换算成微米。

先确认侧栏「点样孔直径」里的数。 默认是 3.4。板子不一样就改成你自己的数。这个数填错，量出来的每个长度都会跟着错。

打开照片时，工具会先自己猜一个圆。你要做的是把它拖准 —— 拖动下面这几个点：

自动放的圆只是起点。 工具现在用视觉模型来猜圆，一般几十毫秒就出来；孔拍得完整时也会尽量套在孔上。 但它不一定每次都准 —— 不管看起来多准，都请自己拖一下确认。 如果圆跑到液滴或旁边的孔上，直接拖到孔上就行。

三个要点

  • 孔拍成正圆，就让它保持正圆 —— 长短轴相等的时候，怎么转都不影响结果。
  • 孔拍成了椭圆，就拉成椭圆，而且要让长轴对准孔真正的直径方向。 比例尺只认长轴：长轴比真实直径短一点，量出来的数就全都偏小一点。
  • 拖到大致准就够。这个工具的目标是「算出大概多长」，不是像素级的精测。 圆和孔边缘差一两个像素，对结果没有看得出的影响。

为什么是长轴？ 孔是圆的，拍斜了成像就是椭圆 —— 拍照这一下把某一个方向压短了，另一个方向没动。 没被压短的那个方向就是长轴，它还是真实的直径。

05量长度

注意起点。 从空白处开始拖才是画线。要是按在圆点、十字或者测量线上，那就是在拖那个东西、或者在挪照片 —— 不是画线。按错了松开重拖就行，不会弄坏什么。

06放大、缩小、挪照片

想干什么怎么做
放大 / 缩小滚轮前后滚。以鼠标指的地方为中心放大，所以先把鼠标挪到晶体上再滚。
挪照片按住鼠标中键（滚轮按下去）或者右键，拖着走。
回到最初的样子双击画布任意位置。

拖到找不着了？ 双击一下就能复位。照片不会丢，圆和测量线也都在，只是视图回到了起点。

07测量记录：改备注、删一条、反悔

侧栏「测量记录」下面列着这张照片上的每一条线：颜色（和图上那条对应）、长度、备注框、✕。

  • 写备注：点备注框打字，点一下别的地方就自动存好了。比如写「左边那颗」。
  • 删一条：点那行的 ✕。
  • 撤销：Ctrl+Z。侧栏「撤销」按钮上也写着你下一步会撤销掉什么（比如「撤销：清空 3 条」），照着看一眼再点更稳。
  • 重做：Ctrl+Shift+Z。撤销撤多了就用它。
  • 清空：一次删掉这张照片的全部记录。
  • 关掉这张：把照片从屏幕上拿开，回到空白页。照片和测量记录都还在，顶栏下拉框里能选回来。

能撤销的操作包括：画线、删线、改备注、挪标签、清空。撤销链会一直留着，刷新页面也不会丢。

08图上那些字和线长什么样

侧栏「导出」栏里有两个滑块，管的就是画在照片上的那些东西：

滑块管什么
字号（10–34） 长度数字和标尺上的字。两处是同一个字号，调一次两边一起变。
线宽（1–8） 测量线有多粗，两端的圆点也跟着同比例变大小。默认 2；嫌粗还能再往下调到 1。

拖滑块的时候画面立刻跟着变，合适了就松手 —— 这两个值会记住，下次打开还是它，换照片也不变。

字和线是「照片的一部分」。 它们跟着照片一起缩放：你放大看晶体时，字和线在屏幕上跟着变大；缩小看全图时，它们跟着变小。 也就是说 —— 字和线相对照片的大小始终是固定的。

这么设计是为了导出的图和你屏幕上看到的完全一样：你在这里调成什么样，导出就是什么样， 不会出现「屏幕上看着正好、导出之后字变小了」这种事。

10看不清楚？调一下画质

侧栏「画质调整」有三个滑块：亮度、对比度、饱和度。晶体和背景颜色太接近的时候，拉一拉对比度会好找很多。

  • 自动调 —— 工具看一眼这张照片的明暗，自己给一组数。不知道从哪下手就点它。
  • 还原 —— 全部回到原样。
  • 按住这里看原图 —— 按住不放，画面变回没调过的样子；松手又回到你调好的样子。用来对照。

只影响「看起来」和「导出的图片」。 原图一个像素都不改，也不影响任何测量数值。调坏了点「还原」就行。

11导出图片

侧栏最下面「导出」那一栏，从上到下就是导出前的几件事。

要不要裁一下

拍照时为了把孔拍全，往往取景取得比较大，晶体只占中间一小块。勾上「裁剪」，就能只导出晶体周围那部分。

  • 快速裁剪下拉框里可以直接选 「聚焦 #N」 —— 框会自动套在那条测量线周围，一步到位。选「不裁剪（整张）」就回到原图。
  • 打开裁剪的时候，圆和十字这些辅助线会藏起来，这样你看到的就是裁完的样子。
  • 「回到原图」按钮随时能把框去掉。

裁完就看不见标定圆了。 长度照样算得对（比例尺是按每张照片单独存的），但圆看不见就没法再拖它重新标定。 想重新标定，先点「回到原图」把框去掉。

标尺放哪、导多大

选项说明
标尺位置 右下 / 左下 / 右上 / 左上。默认右下。挑一个不压住晶体的角。
输出倍率 1×（原尺寸）/ 2× / 4×（推荐）。4× 出来最清楚，标注和照片都够利落。 要是这张图太大、4× 存不下，工具会自动降到装得下的倍率，不会报错让你白忙。

标尺一定会保留。 没有标尺的图，别人没法判断大小 —— 所以不管怎么裁、怎么设，导出的图上都带着标尺。

两个导出按钮

  • 导出图片 —— 出一个 PNG。你在屏幕上看到什么样，它就是什么样（裁剪、标尺位置、字号、线宽、画质调整全都带上）。
  • 导出表格 —— 把这张照片上所有测量记录导成一个 CSV 表格，Excel 能直接打开。文件名是「照片名_测量记录.csv」。

12图库页：照片都在这儿

点测量页左上角的「图库」进来。这张页面上是工具里所有照片。

找照片

  • 搜名字 —— 顶栏左边那个搜索框，打字就筛。
  • 排序 —— 按导入时间或名字排。
  • 只看已测量 / 未测量 —— 忘了哪张还没量，用这个筛。

点任意一张卡片就进测量页开始量。

文件夹（左边那一列）

照片可以归类到文件夹里，比如按样品分。底部五个按钮：新建 / 改名 / 移动 / 复制 / 删除。

删文件夹之前看一眼。 弹窗会告诉你有多少张照片会受影响。拿不准就先复制，别直接删。

一次处理好几张：选择模式

  1. 点顶栏的「选择」 —— 卡片左上角冒出勾选框。
  2. 点卡片勾选（这时点卡片是勾选，不会跳去测量页）。用「全选本页」或「选中全部 N 张」批量勾。
  3. 然后挑一个动作：
    • 打标签 —— 给这批照片加上标记，方便以后再筛。
    • 导出图片 —— 一次把这批照片全导出来。
    • 归档… —— 把这批照片放进文件夹。可以选「也放进这些文件夹」（原来在的都保留） 或「换成这些文件夹」（原来的一律取消）。默认是安全的那一边。
    • 删除 —— 弹窗会先告诉你删掉几张、有多少条测量记录会一起没。
  4. 点「退出」或者按 Esc 回到普通模式。

13手机传图：拍完直接传进电脑

前提：手机和电脑在同一个网络

最省事的办法：用手机开热点，让电脑连上这个热点。这样两边肯定在同一个网里。

传图不花流量。 照片是从手机直接走到电脑的，走的是局域网，上传本身不消耗手机流量。 会花流量的是：电脑连上手机热点之后的其它上网（浏览器、微信、系统更新）。

具体步骤

  1. 先在电脑上图库进入要放的文件夹，再点顶栏「手机传图」 —— 手机上这批照片就默认放进这个文件夹。
  2. 弹窗里出现二维码，下面还写着一行网址。口子会开 2 小时，弹窗上写着还剩多久。
  3. 手机连上同一个 WiFi，用相机或微信扫这个码 —— 手机会打开一个网页。
  4. 在手机上拍照或选照片，填好编号和孔位；有网就点上传，没网就先留着（见下一节）。

晶体房没网？先拍先存，出来自动补传

手机页面上写着「选好照片先存在手机里，填好编号和孔位；回到有网的地方，这个页面会自动一张张传到电脑」。 这就是给晶体房弱网准备的：拍一张、填一张、先存手机，走到有网的地方再自动传。

  1. 电脑上图库先进入要放的文件夹，再点「手机传图」，手机扫码打开页面。这个窗口要一直开着（最长 2 小时）。
  2. 在手机上点「拍照 / 选照片」。每拍一张，下面就多一行「待上传」。
  3. 在那一行填编号、选行 / 列 / 第几个孔。编号 + 孔位会拼成照片名字（比如 50-PEG-G-8-1）。
  4. 没网也没关系：照片已经存在手机里，状态会写「等有网自动传」。不要把手机浏览器关掉，也不要清理浏览器数据。
  5. 有网时把手机页面放在前台，它会自动一张张传；也可以点底部「现在全部传」。 传完直接进图库，「传送记录」里显示的就是你填的名字。

待上传列表里点一下缩略图，可以全屏看大图。 传之前想确认哪张填错了，点开看一眼；觉得不对可以按 ✕ 删掉重拍。

手机队列跟着网址走。 电脑换了 WiFi、插了网线或换了端口，手机上的旧页面就找不到队列了 —— 回办公室先传完，别攒到第二天。 电脑上的「手机传图」窗口过了 2 小时会关；回去重新点一次「手机传图」，手机扫新码打开，队列还在，会接着传。

网页里拍的照片不在 iPhone 相册里；传上去之前，手机浏览器里是唯一一份。别用无痕模式，也别清理浏览器数据。

能存多少张？一般三四十张没问题；手机空间不够时，页面会提示「先把已经拍的传上去，再来拍」。

二维码旁边通常还有一个下拉框，写着「手机连不上？换下面这张网卡再试」。 电脑上装过 VPN、WSL、虚拟机的话会有好几张网卡，第一张不一定对 —— 换个地址，二维码跟着一起换。

连不上怎么办

按这个顺序查，一般前两条就好了：

  1. 弹窗是刚打开的吗？ —— 不是就关掉弹窗，重新点一次「手机传图」。
  2. 手机和电脑是同一个 WiFi 吗？ —— 手机开着流量、连的是 4G/5G，就一定连不上。 手机连的 WiFi 名字要和电脑连的一模一样。
  3. 换个网卡试试 —— 弹窗里那个下拉框，换一张再看。
  4. 防火墙 —— 第一次启动时如果点了「取消」，Windows 就没放行。补救： 控制面板 → Windows Defender 防火墙 → 高级设置 → 入站规则 → 新建规则 → 程序 → 选 D:\anaconda3\python.exe → 允许连接 → 只勾「专用网络」。
  5. WiFi 本身不让设备互通 —— 有些单位/访客 WiFi 会禁止手机和电脑互相访问，怎么设都不通。 换成手机开热点，电脑连热点，立刻就好。

换了网络，一定要重开一次弹窗。 网址是每次打开弹窗的那一刻现算的。换了 WiFi、插了网线、开了 VPN，地址就变了 —— 这时候扫之前那张旧二维码必然连不上。

正确做法：关掉弹窗 → 重新点「手机传图」→ 扫新出来的码。 工具不用重启。

重启工具之后，要重新点一次「手机传图」。 那个「开 2 小时」的口子是跟着工具运行的，工具一关就没了。 忘了点的话，手机上只会看到一句「这个地址只能在电脑上打开」，看不出是没开开关。

（比如下拉框还显示文件夹名）		 按 Ctrl+F5 强制刷新；还不行就关掉标签页重新打开。 浏览器会缓存旧页面，服务端其实已经是新版本。
提示「这个功能在当前运行的版本里没有」 有个旧版本的工具还在跑。关掉那个黑窗口，重新双击 启动.bat。
照片读不出来 格式不支持，或者文件本身是坏的。支持 JPG / PNG / TIF / BMP。
如果是 iPhone 拍的 HEIC，工具读不了 —— 把手机「设置 → 相机 → 格式」改成「兼容性最佳」再拍，或者先转成 JPG。
量出来的数看着不对 按顺序查：① 侧栏「点样孔直径」是不是 3.4（或者你自己板子的数）； ② 标定圆有没有套准孔，有没有对准长轴；③ 这条线是不是量在晶体两头。
自动放的圆跑到液滴或旁边的孔上 直接拖到孔上就行。自动圆只是起点，不是最终标定；完整孔的识别已经改善， 但仍要按第 04 节自己核对一遍。
手机扫码打不开网页 见第 13 节「连不上怎么办」，五步挨个试。
手机离线拍的照片没传上去 回电脑重新点「手机传图」，手机扫新码打开；照片还在手机浏览器里，会接着传。 别清理 Safari 数据、别用无痕模式。电脑换了网络/端口后，旧地址的队列看不到 —— 回办公室先传完。
导出说图太大 工具会自动降档，一般不用管。实在要更大，就先框选裁小一点、或者把「输出倍率」调低一档。
删错了照片 照片文件本身挪到了 data\trash\ 里，能从那儿找回来。 但那张照片上的测量记录是真没了，撤不回来。

一条通用的办法。 这个工具出的大部分怪问题，都是「旧版本还在跑」或者「黑窗口关了」。 遇到说不清的情况，关掉黑窗口 → 重新双击 启动.bat → 刷新一下网页， 十有八九就好了。
