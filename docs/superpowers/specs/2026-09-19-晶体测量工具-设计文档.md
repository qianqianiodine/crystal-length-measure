## 1. 目标与边界

### 1.1 一句话目标
把手机对着显微镜目镜拍的坐滴板照片导进来，标定出「微米/像素」，在图上拉线量出晶体长度，并导出可直接用于论文的标注图和 CSV 记录。

### 1.2 用户与场景
- 单用户，晶体学实验人员，非计算机专业
- Windows 10 电脑本地运行
- 图像来源：手机对着显微镜目镜拍摄（画面含目镜视场圆、暗角、轻微倾斜）
- 用途排序：**① 论文/报告出图 ② 长期存档待查**

### 1.3 已确认的实物规格（来自厂商）
| 项 | 值 | 来源 |
|---|---|---|
| 板型号 | XtalQuest XQ-P-96S-E（96 Well 2 Big Drops Sitting Drop Plate） | 需求文档 + 厂商页 |
| 点样孔 | 圆形 **Φ3.4mm × H0.6mm**，每池 2 孔 | 厂商规格页 |
| 母液池 | 矩形 6.3mm × 3.6mm | 厂商规格页 |
| 板体 | 127.8mm × 85.5mm，8 行 × 12 列 | SBS 标准 |
| 孔间距 | **9.0mm**（SBS 标准） | ANSI/SBS |

**标定基准优先级**：孔直径 3.4mm（首选，用户已确认）→ 孔间距 9.0mm（备选，标准值）。

### 1.4 已知的测量学风险
1. **系统性偏差 > 随机误差**：标定系数若有 x% 误差，所有晶体长度同比例偏 x%，且方向一致、无法通过增加样本平均掉。因此标定环节的精度与可追溯性优先于一切。
2. **孔壁边界模糊**：样品集实测图像灰度标准差仅 ~13，孔壁为渐变过渡。自动边缘检测得到的孔径可能稳定地偏离真值。**故必须保留手动拉线路径，且手动路径是可信度下限的保证。**
3. **椭圆问题**：板面倾斜会使圆孔成像为椭圆。两种应对：做透视校正恢复成正圆；或不做校正、按需求取椭圆长轴标定。
4. **第一阶段验收硬指标**：用样品集实测并与游标卡尺读数比对，测量误差需 < 2%。达不到则需回头改标定方案，不进入后续阶段。

## 3. 核心架构：非破坏性变换链

**整个工具最重要的设计决策。**

### 3.1 原则
**原图永不修改。** 所有处理都表达为可重放的参数，存进数据库；任何一步改了，下游全部重新计算。

```
原图 (data/images/originals/, 永不改动)
  │
  ├─ 透视校正矩阵 H (3×3, 可空=不校正)
  │
  ├─ 增强参数 {clahe_clip, denoise_h, sharpen_amount}
  │
  ├─ 标定 {type, pixel_length, real_length_um}  → 系数 μm/px
  │
  └─ 测量线端点 (原图像素坐标)
```

### 3.2 坐标变换链（数学定义，实现必须严格遵循）

设原图坐标 `p0`，逐级变换：

```
p1 = H · p0                                  (透视校正)
p2 = M_enh · p1                              (增强是逐像素的，不改变几何)
  → 因此增强步骤对坐标是恒等变换，可跳过
scale = real_length_um / pixel_length_um     (标定系数，μm/px)
```

**关键结论**：增强（CLAHE/降噪/锐化/光照均衡）都**不改变像素坐标**，所以变换链里只有 **H** 和 **scale** 两个量影响测量结果。这大幅简化了实现与调试。

### 3.3 测量的正反向计算
- **正向（测量时算数）**：用户在**显示图**上拉线 → 端点坐标在显示图坐标系 → 逆变换回 `p0` → 存储 `p0` 端点
- **反向（显示数值）**：`p0` 端点 → 经 H 变换 → 算像素欧氏距离 → × scale → μm

**为什么反过来强调**：存的是原图坐标，所以任何时候改标定/改校正，只需重算显示，数据本身不动。

### 3.4 深度增强的例外
超分辨率会改变分辨率，即改变 scale，导致标定失效。**第一阶段不做**。若将来做，必须走独立分支：清空标定 → 提示重新标定（需求文档 3.5.5 已规定此行为）。

## 5. 处理管线

### 5.1 校正（可跳过）
1. **自动尝试**：检测孔的弯月面亮环 → 拟合椭圆 → 若长短轴比 > 阈值（如 1.05）→ 用椭圆参数求单应矩阵 H，把椭圆恢复成正圆
2. **手动**：用户点板框（或孔边界）四个角点 → 求 H
3. **跳过**：H = null，后续标定取椭圆长轴
4. 可撤销（H 置回 null）

> 需求文档 3.4.2 的「利用孔间距 9mm 自动校正」依赖至少 4 个孔心。样品集实测部分图仅见 1–2 个孔，该路径会频繁失败，故**手动四角点为主路径**。

### 5.2 质量评估（只提示，不自动改）
| 指标 | 方法 |
|---|---|
| 模糊度 | 拉普拉斯方差 |
| 对比度 | 灰度标准差 |
| 噪声 | skimage `restoration.estimate_sigma` |
| 光照均匀性 | 大尺度高斯背景的梯度分布 |

输出中文提示，例如「检测到对比度偏低，建议增强」。

### 5.3 增强
- 对比度：CLAHE (`cv2.createCLAHE`)
- 降噪：`cv2.fastNlMeansDenoising` 或双边滤波
- 锐化：USM（高斯模糊 + 加权）
- 光照均衡：形态学开运算估计背景后相减
- 三个滑块实时预览；「按住看原图」对比
- **不改变坐标**，故不影响标定

### 5.4 孔检测
1. 预处理：自动裁掉目镜视场圆外的暗角区域
2. **主检测目标：液滴弯月面亮环**（比孔壁边界锐利、形状规整得多）
3. 候选生成：轮廓提取 + `cv2.fitEllipse`
4. 评分排序，给出 2–3 个候选供点选
5. 失败兜底 → 手动拉线

**候选评分维度**：圆度/椭圆拟合残差、边缘梯度强度、尺寸是否符合先验（孔径应在合理像素范围内）、是否在有效画面区域内。

### 5.5 测量交互
- 按住拖拽画线；拖拽中实时显示长度
- 每条线自动分配颜色 + 编号
- 端点做**亚像素级精确拾取**（非整数像素），避免 >2% 精度要求被端点取整误差吃掉
- 点线选中 → Delete 删除；框选批量删除；撤销上一步；清空全部（二次确认）

### 5.6 导出

#### 5.6.1 CSV
字段：图像名、图像 ID、测量编号、起终点、像素长、实际长(μm)、标定系数、备注、时间

#### 5.6.2 标注 PNG（出版级）

**导出裁剪（用户明确要求的核心功能）**

场景：拍照时为了拍到孔，取景不得不放宽，构图不美观。导出时希望裁掉多余部分、聚焦晶体，但**标尺必须保留**（论文图无标尺则不可信）。

- 用户可在图上拖拽选择**矩形裁剪区域**，实时预览
- 提供「聚焦选中测量线」快捷按钮：自动以某条测量线为中心留出边距生成裁剪框
- 裁剪区域可手动拖角调整、可重设、可取消（取消 = 导出全图）
- 提供常用比例预设（1:1 / 4:3 / 3:2 / 16:9）与「不限制」

**标尺（Scale Bar）**

- **物理长度固定、像素长度自适应**——这是科学出版的正确做法：标尺代表一个确定的物理量
- 自动选择"好看"的物理长度：在 `{10,20,50,100,200,500,1000,2000} μm` 中，选出像素宽度最接近**裁剪宽度 10%~25%** 的那个
- 单位智能切换：μm（<1000μm）/ mm / cm
- 默认位置：右下角，可拖动或选四角
- 样式：黑白双线（保证在任何背景上都可见）+ 加粗端点
- 标签显示物理值，如 `200 μm`

**其他绘制元素**
- 在**校正+增强后**的图上绘制
- 测量线 + 端点标记 + 长度数值
- 可选：测量编号、备注文字
- 高分辨率输出（默认 2× 超采样），线宽/字号随输出尺寸自适应
- 导出分辨率可调（如 1×/2×/4×），满足不同期刊要求

**重要不变式**：裁剪**不改变** μm/px 系数，纯属显示层操作；导出图内的所有长度数值与裁剪前一致。

## 7. 分阶段范围

### 第一阶段（本次实施）
测量闭环，对应需求文档约 1/3：

- ✅ 导入：拖拽 / 文件选择 / 剪贴板 / 手机扫码
- ✅ 命名 + 入库 + 名称冲突处理
- ✅ 透视校正（手动四角点为主 + 自动尝试 + 跳过 + 撤销）
- ✅ 质量评估 + 增强（自动 + 三滑块手动 + 对比原图）
- ✅ 标定三条路径（自动 / 自动+微调 / 手动拉线）
- ✅ 拉线测量 + 实时显示 + 撤销 + 删除 + 备注
- ✅ 测量记录表
- ✅ CSV 导出 + 标注图导出（含**导出裁剪**与**自适应标尺**，见 5.6.2）
- ✅ 基础画廊
- ❌ 不做：镜头畸变棋盘格标定、深度增强/超分、批量测量

### 第二阶段
图像管理：标签系统、收藏、筛选、排序、搜索、文件夹（可移动/复制/删除/套层）、批量操作、批量导出

### 第三阶段（可选）
全自动校正、批量自动测量、深度增强（需带重新标定流程）

### 明确砍掉
- **手机镜头畸变棋盘格标定**：图像来自目镜拍摄，主要误差是透视而非镜头畸变；且用户无棋盘格样本。若将来需要，可作为独立功能补。
- **深度增强/超分**：会改变像素尺寸使标定失效，且 AI 生成的纹理可能伪造晶体边缘，直接威胁测量真实性。

## 9. 测试策略

### 9.1 样品的正确用法（来自技术建议书 + 用户说明）
样品集为**两个标本**，每个标本各有多次拍摄：

| 样品 | 用途 |
|---|---|
| `样品1_全局.jpg` / `样品1_部分1.png` / `样品1_部分2.jpg` | **标本 1**：不同视野（全局 + 两个局部）。测试清晰度差异下的测量稳定性 |
| `样品2_1.jpg` / `样品2_2.jpg` | **标本 2**：同一标本两次拍摄 → **重复性测试**（同一晶体测两次，结果应一致） |
| `A4纸上的晶体板_1.jpg` / `_2.jpg` | **孔直径实证**：板放在标准 A4 纸上，用 A4 尺寸（210×297mm）反推比例尺验证孔径 |
| `小孔细节.jpg` + `小孔细节_红圈标注过大致位置.pdf` | 孔结构细节、孔检测算法调试 |

> 注：`样品2_2.jpg` 与先前的 `样品1_2.jpg` 为同一文件（MD5 一致），用户重新归类为标本 2 的第二张。
> `样品1_全局.jpg` 含目镜视场圆与暗角；`样品1_部分1.png` 晶体最清晰（透明薄片状，带淡黄色调）——两张构成清晰度跨度，适合验证增强模块的效果。

### 9.2 分层测试
- **单元测试**：坐标变换链的正反向一致性（这是正确性的根基）；标定系数计算；CSV 格式
- **集成测试**：导入 → 标定 → 测量 → 导出 全流程（用样品集真实图片）
- **精度验证（硬门槛）**：用 A4 纸上拍的板照片反推标定系数，与游标卡尺实测对比，误差 < 2%

### 9.3 关键回归点
- 改标定后，已有测量值的重算是否正确
